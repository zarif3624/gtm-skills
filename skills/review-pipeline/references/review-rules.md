# Pipeline Review Rules

Adapt thresholds to the team's historical data. When history is unavailable, label defaults as provisional.

Flag a deal for validation when any of these apply:

- no next step, owner, or date;
- next-step date is in the past;
- close date precedes a required buyer milestone;
- amount or probability changed without a note;
- stage exit criteria are unsupported;
- no meaningful buyer action within the expected stage duration;
- close date slipped repeatedly;
- single-threaded access in a complex decision;
- seller activity is present but buyer progress is absent;
- a fatal qualification contradiction is unresolved.

Do not use email count, meeting count, or recent seller activity as automatic evidence of momentum. Prefer accepted buyer actions, completed validation, stakeholder progress, and resolved decisions.
