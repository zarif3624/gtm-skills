# ICP Scoring Guide

Use a 100-point score only when the available data can support the distinctions.

| Dimension | Suggested range | Question |
| --- | ---: | --- |
| Problem fit | 0-30 | Is the target problem present and costly? |
| Ability to realize value | 0-20 | Can the account implement and adopt the solution? |
| Company fit | 0-20 | Do observable firmographics match successful customers? |
| Timing or trigger | 0-15 | Is there a verified reason to act now? |
| Commercial fit | 0-10 | Can the account support the delivery and contract model? |
| Strategic learning value | 0-5 | Would this account test an important hypothesis? |

Do not hide missing data inside a neutral score. Mark it `Unknown`, calculate a score range, and explain which evidence would narrow it.

Suggested tiers:

- **Tier 1:** 80-100 with no hard disqualifier
- **Tier 2:** 60-79 or one important unknown
- **Tier 3:** 40-59, useful mainly for learning or nurture
- **Do not pursue:** below 40 or any hard disqualifier

Calibrate thresholds against actual outcomes instead of treating these defaults as universal.
