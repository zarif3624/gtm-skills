# Playbooks

Skill sequences for the four people who use this project most. Each playbook is a first-week plan: which skills to install, what to feed them, what artifact to expect at each step, and where the evidence rules protect you.

| You are | Start here |
| --- | --- |
| A founder doing founder-led sales | [Founder playbook](founder.md) |
| An account executive carrying a quota | [Account executive playbook](account-executive.md) |
| An SDR or BDR building pipeline | [SDR playbook](sdr.md) |
| A RevOps or sales leader running the system | [RevOps leader playbook](revops-leader.md) |

Every playbook uses the same rules as the skills themselves: facts, inferences, and unknowns stay separate; nothing is fabricated to look complete. If a step produces an artifact full of `Unknown` labels, that is the system working — it is showing you what evidence to collect next, not failing to impress you.

Not sure which playbook fits? Start with the [ten-minute quickstart](../../QUICKSTART.md) instead, or grab a single prompt from the [prompt cookbook](../prompt-cookbook.md).
